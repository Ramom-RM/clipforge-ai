ClipForge AI é uma aplicação web que utiliza inteligência artificial para analisar vídeos e gerar **cortes inteligentes automaticamente**.

## 🚀 Funcionalidades

- Upload de vídeo
- Transcrição automática
- Análise com IA
- Seleção inteligente de trechos
- Corte automático do vídeo
- Download do vídeo final

## 🛠 Tecnologias

- HTML
- CSS
- JavaScript
- Gemini AI
- Cloudinary
